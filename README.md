**Python Data Analysis with NumPy and Pandas**

A beginner-friendly data analysis project demonstrating how NumPy and Pandas can be used to work with numerical and structured datasets in Python.

**Project Overview**

This project explores practical data analysis techniques using two of Python's most widely used data science libraries:

NumPy for numerical computations and array operations

Pandas for data manipulation, filtering, indexing, grouping, and analysis

The project uses two example datasets:

Temperature Data — Analysis of daily temperatures across two weeks

Transaction Data — Analysis of product transactions across different regions

**Technologies Used**

Python

NumPy

Pandas

Jupyter Notebook / Google Colab

1. **NumPy**

Creating 1D and 2D arrays

Inspecting array shape, data type, and size

Celsius to Fahrenheit conversion

Finding maximum, minimum, and mean values

Array indexing

Extracting rows and columns from 2D arrays

2. **Pandas Series**
   
Creating Series with custom indexes

Creating DataFrames

Exploring data using head() and tail()

Checking shape, columns, and data types

Selecting specific columns

Filtering data using multiple conditions

Counting categorical values

Finding unique values

Grouping data and calculating averages

Updating existing values

Creating calculated columns

Removing rows and columns
